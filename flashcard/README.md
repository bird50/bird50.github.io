# Recall — Flashcard Studio

เว็บ Flashcard ภาษาไทยแบบ static ไม่มี backend และไม่มี dependency ฝั่ง JavaScript

## เริ่มใช้งาน

ดับเบิลคลิก `index.html` เพื่อเปิดใน Chrome หรือ Edge ได้ทันที ไม่ต้องติดตั้ง Node/Python ไม่ต้อง build และไม่ต้องรัน server

ไฟล์ `index.html` รวม CSS, JavaScript และ JSON Schema ไว้แล้ว สามารถคัดลอกไฟล์เดียวไปใช้ได้ รูปภาพที่อัปโหลดใช้งานได้โดยไม่ต้องต่ออินเทอร์เน็ต ส่วนภาพจากลิงก์ HTTPS ยังต้องใช้อินเทอร์เน็ต

ข้อมูลเก่าที่เคยเปิดผ่าน localhost จะไม่ย้ายมายังไฟล์ HTML อัตโนมัติ ให้นำเข้าไฟล์ JSON ที่ส่งออกจากเว็บเดิม

## ฟีเจอร์

- สร้าง แก้ไข ลบสำรับและการ์ด ค้นหาชื่อ คำอธิบาย และแท็ก
- ข้อความและภาพทั้งสองด้าน รองรับอัปโหลด PNG/JPEG/WebP/GIF ไม่เกิน 5 MB ต่อรูป
- เก็บสำรับ ภาพ และสถานะจำได้ใน IndexedDB บนเบราว์เซอร์
- ทบทวนด้วยแอนิเมชันพลิกการ์ด 3D: กรอบคำถามสีฟ้า / คำตอบสีเขียว แล้วเลือกระดับ ยังจำไม่ได้ / ยังไม่แน่ใจ / จำได้แล้ว พร้อมสรุปจำนวนแต่ละระดับ (สถานะเดิมยังใช้ได้)
- นำเข้าและส่งออก JSON รายสำรับ หรือสำรองเนื้อหาทุกสำรับพร้อมภาพที่อัปโหลด
- สร้าง Prompt สำหรับ AI และดาวน์โหลด JSON ตัวอย่าง / JSON Schema จากในแอป

## มาตรฐานสำรับ

`deck.schema.json` เป็น JSON Schema Draft 2020-12 ของ **Recall Deck v1** ซึ่งเป็นรูปแบบที่กำหนดให้โปรเจกต์นี้ ไม่ใช่มาตรฐาน Anki หรือมาตรฐานสากล

```json
{
  "format": "recall.deck",
  "version": 1,
  "id": "biology-01",
  "title": "ชีววิทยา",
  "description": "ทบทวนเรื่องเซลล์",
  "tags": ["วิทยาศาสตร์"],
  "cards": [
    {
      "id": "card-1",
      "front": {"text": "ออร์แกเนลล์ใดทำหน้าที่สังเคราะห์โปรตีน?"},
      "back": {"text": "ไรโบโซม"}
    }
  ]
}
```

แต่ละด้านต้องมี `text` เป็น string และมีข้อความที่ไม่ว่างหรือ `image` รูปภาพใช้ `{"src":"https://... หรือ data:image/png;base64,...","alt":"คำอธิบาย"}` โดย data URL รองรับ png/jpeg/webp/gif การ์ดแต่ละใบต้องมี id ไม่ซ้ำกันภายในสำรับ (แอปตรวจเพิ่มจาก Schema)

ไฟล์หลายสำรับใช้ `{"format":"recall.collection","version":1,"decks":[...]}` ถ้า id สำรับชนกับของเดิม แอปถามก่อนแทนที่ นำเข้าตรวจครบทุกสำรับแล้วบันทึกใน transaction เดียว

## ข้อควรทราบ

ข้อมูลผูกกับ browser profile และตำแหน่งที่เปิดไฟล์ การย้ายหรือเปลี่ยนชื่อไฟล์อาจทำให้เบราว์เซอร์ใช้พื้นที่จัดเก็บคนละชุด การล้างข้อมูลเว็บไซต์หรือใช้โหมดส่วนตัวอาจทำให้ข้อมูลหาย ควรส่งออกสำรองเป็นระยะ JSON สำรองเนื้อหาสำรับ ไม่รวมสถิติการทบทวน รูปที่อัปโหลดจะฝังใน JSON ส่วนรูป HTTPS เป็นลิงก์และต้องมีอินเทอร์เน็ต ไม่มีการเรียก AI API หรือเก็บ API key; ผู้ใช้คัดลอก Prompt ไปใช้กับ AI เอง

## สำหรับผู้พัฒนา

หลังแก้ไข `app.js`, `model.js`, `style.css` หรือ `deck.schema.json` ให้รัน `npm run build` เพื่ออัปเดต HTML ไฟล์เดียว ผู้ใช้งานไฟล์ HTML ไม่ต้องรันคำสั่งนี้

## สำรับแผนที่ 77 จังหวัด

มีสำรับ **จำ 77 จังหวัดจากแผนที่ประเทศไทย** ฝังมาใน HTML และเพิ่มเข้าคลังครั้งแรกโดยอัตโนมัติ แต่ละการ์ดไฮไลท์จังหวัดด้วยสีส้มบนแผนที่พร้อมภาพขยาย ใช้ออฟไลน์ได้ ส่งต่อแยกสำรับด้วย `decks/thailand-77-provinces.deck.json` ดูที่มาและรายละเอียดใน `decks/README.md`

## สำรับ Oxford 3000 จาก CSV ของผู้ใช้

เปิด HTML ใหม่แล้วสำรับ A1 (826 ใบ), A2 (799 ใบ), B1 (742 ใบ), B2 (668 ใบ) จะเพิ่มอัตโนมัติครั้งเดียวโดยไม่ทับสำรับเดิม ด้านหน้าคือคำศัพท์และชนิดคำ ด้านหลังคือคำแปลไทย ประโยคตัวอย่างและคำแปลประโยคตาม CSV

นำเข้าแยกสำรับได้จาก `decks/oxford3000-a1.deck.json` (และ a2/b1/b2) หรือทั้งสี่สำรับจาก `decks/oxford3000-all.collection.json`

ต้นฉบับ `oxford3000.csv` มี 2,753 แถว (2,747 หัวคำไม่ซ้ำ) ไม่ใช่ 3,000 แถว มี 273 แถวที่ระบุหลายระดับ จึงใส่ในทุกระดับที่ระบุ รวม 3,035 การ์ดข้ามสำรับ ต้นฉบับไม่ได้จับคู่ความหมาย/ชนิดคำกับแต่ละระดับอย่างละเอียด จึงคงเนื้อหาเดิมและแสดงหมายเหตุบนการ์ดที่เกี่ยวข้อง ไม่ได้เติมคำที่ขาดหรืออ้างว่าตรวจรับรองรายการกับ Oxford แล้ว

สร้างซ้ำจากสำเนา CSV: `python3 scripts/create-oxford-decks.py` แล้ว `npm run build`

## ทบทวนแบบสุ่ม

กด **⤨ ทบทวนแบบสุ่ม** บนสำรับเพื่อสับลำดับการ์ดที่ยังจำไม่ได้หรือยังไม่แน่ใจโดยไม่ซ้ำภายในรอบ ลำดับที่บันทึกไว้ในสำรับยังเหมือนเดิม เมื่อจบรอบกด **สุ่มทบทวนอีกครั้ง** เพื่อสุ่มลำดับรอบใหม่ สถานะการจำทั้งสามระดับยังบันทึกตามการ์ดเดิม

ทั้งโหมดตามลำดับและแบบสุ่มข้ามการ์ดที่จำได้แล้วอัตโนมัติ รวมถึงเมื่อเริ่มรอบใหม่ หากจำได้ครบทุกใบจะแสดงข้อความว่าไม่มีการ์ดที่ต้องทบทวน

## รีเซ็ตสถานะรายสำรับ

กด **↺ รีเซ็ตสถานะ** บนสำรับ แล้วยืนยัน การ์ดทั้งหมดในสำรับนั้นจะกลับเป็น **ยังจำไม่ได้** และเข้าร่วมการทบทวนอีกครั้ง เนื้อหาการ์ดและสถานะของสำรับอื่นยังอยู่ครบ

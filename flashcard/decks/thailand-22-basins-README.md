# จำ 22 ลุ่มน้ำจากแผนที่ประเทศไทย

สำรับ 22 ใบ หน้าคำถามแสดงขอบเขตลุ่มน้ำทั้งประเทศ ไฮไลท์ลุ่มน้ำเป้าหมายสีส้มและภาพขยาย ด้านหลังเป็นชื่อภาษาไทย ไม่ใส่ชื่อหรือรหัสเฉลยบนภาพคำถาม ภาพ PNG ฝังใน JSON ทั้งหมด ใช้ออฟไลน์ได้

เปิด `index.html` ใหม่ สำรับจะเพิ่มครั้งเดียวโดยไม่ทับข้อมูลเดิม หรือเลือกนำเข้า `thailand-22-basins.deck.json` หากเคยลบสำรับ

## ข้อมูลต้นทาง

- ชั้นข้อมูล: พื้นที่ 22 ลุ่มน้ำหลัก (ID 6) บริการ DDPM GIS กรมป้องกันและบรรเทาสาธารณภัย
- URL: https://gis-portal.disaster.go.th/arcgis/rest/services/MapDX/DPM_TH_Hydrology/MapServer/6
- รายการอ้างอิงการแบ่ง 22 ลุ่มน้ำ: สำนักงานทรัพยากรน้ำแห่งชาติ https://gdcatalog.go.th/dataset/gdpublish-dataset-32-0113
- ดาวน์โหลดวันที่ 12 ตุลาคม 2026 เป็น GeoJSON, outSR=4326, maxAllowableOffset=0.002 องศา เพื่อลดรายละเอียดให้เหมาะกับภาพเพื่อการเรียนรู้
- การดัดแปลง: ฉายพิกัด equirectangular อ้างอิงละติจูด 13°, ระบายสีเป้าหมาย เพิ่มภาพขยาย และวาด PNG ด้วย Pillow โดย Recall ไม่ใช้การสร้างภูมิศาสตร์ด้วย AI
- ชั้นบริการไม่ได้ระบุ Copyright Text; หน้าบัญชี ONWR ระบุ License not specified จึงไม่อ้างสัญญาอนุญาตแบบเปิดแทนเจ้าของข้อมูล
- แสดงส่วนของลุ่มน้ำที่อยู่ในประเทศไทย ไม่ใช่พื้นที่รับน้ำทั้งหมดข้ามประเทศ และไม่ใช่แผนที่อ้างอิงแนวเขตทางกฎหมาย

ข้อมูลขอบเขต: `data/thailand-22-basins.geojson`
รายการตรวจสอบชื่อ รหัส และ SHA-256 ภาพ: `decks/thailand-22-basins-manifest.json`
สร้างซ้ำด้วย Python + Pillow: `python scripts/create-basins-deck.py` แล้ว `npm run build` (ผู้ใช้ไม่ต้องรันขั้นตอนนี้)

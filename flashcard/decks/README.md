# จำ 77 จังหวัดจากแผนที่ประเทศไทย

เปิด `../index.html` สำรับจะถูกเพิ่มให้อัตโนมัติครั้งแรก โดยไม่ทับสำรับเดิม หากลบสำรับไปแล้ว ให้นำเข้า `thailand-77-provinces.deck.json` เพื่อเพิ่มอีกครั้ง

ใช้กับ Recall เครื่องอื่นได้ด้วยปุ่ม **นำเข้า JSON** ภาพ PNG ทั้ง 77 ภาพอยู่ในไฟล์แล้ว ไม่ต้องมี server หรืออินเทอร์เน็ต

- หน้าคำถาม: แผนที่ประเทศไทยพร้อมขอบเขตจังหวัด จังหวัดเป้าหมายสีส้ม และภาพขยายบริเวณเดียวกัน
- หลังคำตอบ: ชื่อจังหวัดภาษาไทย
- รวมกรุงเทพมหานครและบึงกาฬ ครบ 77 พื้นที่ ไม่ซ้ำกัน
- เรียงการ์ดแบบสับล่วงหน้า เพื่อไม่ให้เดาคำตอบจากลำดับตัวอักษร
- `thailand-77-manifest.json` บันทึกชื่อจังหวัด รหัส และ SHA-256 ของภาพเพื่อการตรวจสอบ

## แหล่งข้อมูลและสัญญาอนุญาต

ข้อมูลขอบเขตที่ใช้: [Thailand Canonical Administrative-Names Reference](https://github.com/DevelopedbyWill/thailand-canonical-admin-names), `data/v1.0.0/thailand-adm1-polygons-v1.0.0.geojson` ดาวน์โหลด 11 ตุลาคม 2026

ตาม README ของผู้เผยแพร่ ขอบเขตมาจาก **OCHA Common Operational Datasets ผ่าน piyayut-ch/mapthai** และใช้ **[CC BY 3.0 IGO](https://creativecommons.org/licenses/by/3.0/igo/)** ส่วนงานรวบรวมข้อมูลใช้ **[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)** ดูข้อความต้นทางใน `../data/SOURCE-README.md` และ `../data/NOTICE-upstream.md`

การดัดแปลง: ฉายพิกัดแบบ equirectangular ที่ละติจูดอ้างอิง 13° วาดเส้นขอบ ระบายสีจังหวัดเป้าหมาย เพิ่มภาพขยาย และแปลงเป็น PNG สำหรับการเรียนรู้โดย Recall ข้อมูลต้นทางเป็นขอบเขตแบบลดรายละเอียด (ฟิลด์วันที่ 2019-02-18) จึงไม่ใช่แผนที่สำหรับอ้างอิงแนวเขตทางกฎหมาย ไม่มีการรับรองจากเจ้าของข้อมูล

สร้างซ้ำ: ติดตั้ง Pillow แล้วรัน `python scripts/create-thailand-deck.py` จากนั้น `npm run build` เพื่อรวมสำรับใน HTML (ผู้ใช้ทั่วไปไม่ต้องทำขั้นตอนนี้)
